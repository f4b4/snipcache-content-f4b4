# Deutsche Umlaute

### Windows PowerToys Quick Accent

Just press space after the vowel or 's'.

## US-International keyboard layout

- **Keyboard Layout (Win):** `United States-International`
- **Keyboard Layout (KDE):** `English (US, intl., with AltGr dead keys)`

| Character | Shortcut | Uppercase | Shortcut |
|:---:|---|:---:|---|
| **ä** | `AltGr` + `q` | **Ä** | `AltGr` + `Shift` + `q` |
| **ö** | `AltGr` + `p` | **Ö** | `AltGr` + `Shift` + `p` |
| **ü** | `AltGr` + `y` | **Ü** | `AltGr` + `Shift` + `y` |
| **ß** | `AltGr` + `s` | | |

`AltGr` is the **Right Alt** key. These shortcuts are the same on Kubuntu (*English (US, intl., with AltGr dead keys)*) and Windows (*United States-International*).
