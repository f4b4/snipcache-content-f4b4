# SnipCache

f4b4's know-how snippets: recipes, scripts, SQL, keyboard shortcuts and
knowledge captured from AI chats. Use the search (Ctrl+K) or browse the
sidebar.

Every push to [f4b4/snipcache-content-f4b4](https://github.com/f4b4/snipcache-content-f4b4)
republishes this site. Conventions are described in the
[content repo guide](https://github.com/f4b4/snipcache/blob/main/doc/content-repo-guide.md).
